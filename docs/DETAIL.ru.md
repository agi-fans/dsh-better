# Углубление промптов (`dsh-better`)

`dsh-better` переносит в DeepSeek Harness углубление промптов с опорой на кодовую базу (`/better`) и проверку брифов субагентов из [`pi-better`](https://github.com/nicobailon/pi-better).

1. Запустите `/better <черновик>` — поле ввода сразу освобождается, пока помощник только для чтения изучает репозиторий в фоне.
2. Следите за этапами `Поиск → Анализ → Углубление → Доводка` — панель Depth показывает инструменты и потоковую генерацию с переиспользованием KV-кэша.
3. Проверьте перед отправкой — углублённый промпт подставляется в поле ввода с кнопкой **Восстановить исходный** и отправляется только после нажатия `Enter`.

## Справочник настроек (адаптировано из `pi-better`)

В оригинальном `pi-better` настройки задаются в секции `"better"` с полями `model` и `thinking`. `dsh-better` сохраняет полную совместимость и добавляет параметры для субагентов:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `model` | `null` (как в чате) | Маршрут модели (`provider/model`) или группа маршрутизации для `/better`. Наследование активной модели чата позволяет переиспользовать KV-кэш промпта; явный выбор другой модели обменивает кэш на качество или экономию. |
| `reasoningEffort` | `null` (`low` · быстро по умолчанию) | Аналог `thinking` из `pi-better` (`none`, `off`, `low`, `medium`, `high`, `max` или `inherit`). По умолчанию использует быстрый уровень `low` с сохранением KV-кэша и подстраивается под модель. |
| `checkSubagents` | `true` | Включает или отключает предварительную проверку заданий субагентов с префиксом `/better`. |
| `briefModel` | `null` (как `model`) | Отдельная модель только для проверки `/better`-брифов субагентов. |
| `briefReasoningEffort` | `null` (как `reasoningEffort`) | Отдельный уровень рассуждения только для проверки `/better`-брифов субагентов. |

## Способы настройки в DeepSeek Harness

1. **Окно настроек**: Откройте **Настройки → Углубление промпта** в левом нижнем меню (сохраняется автоматически).
2. **Страница плагинов**: Откройте **Плагины → Углубление промптов (`@agi-fans/dsh-better`)** (или строку `@agi-fans/dsh-better#dsh-better`).
3. **Slash-команда (`/better-model`)**: Просмотр и изменение из любого чата или CLI-сессии:
   - `/better-model` — показать текущие настройки и список доступных моделей
   - `/better-model <provider/model> [effort]` — закрепить модель и при желании уровень рассуждения
   - `/better-model effort <level|inherit>` — изменить только уровень рассуждения
   - `/better-model brief <same|inherit|<provider/model>> [effort]` — задать модель проверки брифов субагентов
   - `/better-model subagents <on|off>` — мгновенно включить или отключить проверку субагентов
   - `/better-model reset [all]` — вернуть наследование от сессии (или сбросить все поля)

Изменения из интерфейса и `/better-model` атомарно сохраняются в `dsh-better.settings.json` активного профиля и применяются мгновенно без перезапуска. Значения по умолчанию заданы в `cordis.patch.yml`.
